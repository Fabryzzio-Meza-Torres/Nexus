# Feature — Documentos de consulta
Logística carga/selecciona la lista de requerimientos, PDF/MD o ficha técnica para extraer requerimientos y buscar contra catálogo. Validar formato/tamaño (demo hasta 10 MB); mostrar progreso y error entendible para archivo vacío/ilegible/irrelevante.
Procesar en servidor/memoria; Storage no obligatorio. Extracción validada y evidencia por requisito. Reanálisis no duplica requisitos ni cambia la lista oficial. Resultado vacío muestra «Sin requerimientos» y no crea productos.
Las fichas de fichas tecnicas/ son exclusivamente fixtures de búsqueda/matching, completamente ajenos al importador del catálogo. No incluyen fichas reales en este paquete; usar el documento demo suministrado o colocar archivos de prueba.
