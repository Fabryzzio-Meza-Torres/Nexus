# Feature — Lista oficial
El matching produce propuesta consultable. Proyectista pulsa «Crear lista oficial» para confirmar candidatos y cantidades/unidades; crear registro selections e ítems una sola vez. Se permite draft con revisión técnica pendiente, visible.
Solo Proyectista modifica directamente en draft: agregar, quitar, sustituir, cantidad, prioridad. Cambiar rol mantiene la misma lista. El servicio comprueba rol/estado, datos e IDs; no basta deshabilitar botones.
Logística ve «Solicitar cambio» y formulario con antes/después y razón obligatoria; enviar crea pending sin tocar selection_items ni version. Residente solo consulta.
Ordenar/filtrar es estado de vista y no altera prioridad. Reanalizar genera otra propuesta sin sobrescribir lista. Nuevas incorporaciones requieren acción explícita del Proyectista o ticket aceptado.
Lista finalized queda inmutable; no se implementa reapertura P0. Se consulta/prepara para cotizar. Ver change-requests.md y approval.md.
