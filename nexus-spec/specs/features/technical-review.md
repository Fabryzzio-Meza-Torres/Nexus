# Feature — Revisión técnica
Proyectista es responsable de ambigüedades. Todos pueden consultar alternativas, proveedor, distancia, datos conocidos y desconocidos. Solo Proyectista selecciona o sustituye en la lista y registra nota/resolved.
needs_review cuando diferencia top2 <=5, score <70 o falta evidencia técnica crítica. Una coincidencia de tipo/marca no prueba equivalencia, disponibilidad o cumplimiento normativo.
El seed carece de especificaciones verificadas: mostrar «Especificaciones por verificar». Para demo Proyectista puede registrar aceptación explícita de uso demostrativo; no convierte datos en certificados.
Cambiar producto/requisitos invalida la revisión previa. Cierre requiere resolver revisiones de todos los ítems y faltantes de cobertura. Un rechazo de ticket no resuelve una revisión técnica automáticamente.
