# Importar catálogo
Desde raíz del paquete: `python scripts/catalog/import_catalog.py` (o `py` en Windows).
Python 3, biblioteca estándar. Lee únicamente data/source/catalogo-marcas-por-tipo.csv. Ver specs/catalog-generator.md para transformación y supabase/README.md para seed.
Se incluyen salidas ya generadas. Ejecutar de nuevo sobrescribe únicamente JSON/fixtures/reporte generados; conserva CSV y especificaciones.
