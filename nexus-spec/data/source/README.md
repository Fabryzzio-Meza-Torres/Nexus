# Fuente principal
catalogo-marcas-por-tipo.csv es una copia byte a byte de «catalogo-marcas-por-tipo.xlsx - Catálogo de marcas.csv», adjunto de la conversación Planificación de hackathon.
Se conserva Confianza literalmente como declaración del archivo, sin asumir verificación independiente, presencia comercial actual o disponibilidad. No incluye modelos/SKU, proveedores, ubicaciones, precios, stock ni especificaciones técnicas.
